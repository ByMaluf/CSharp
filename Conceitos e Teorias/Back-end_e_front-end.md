## O que é Back-end?

O **Back-end** é a parte da aplicação que executa **no lado do servidor**. Ele trabalha nos bastidores, sendo responsável pelo processamento dos dados e pela implementação das regras de negócio.

Seu foco não está na interface que o usuário vê, mas em **receber, validar, processar e devolver informações** de forma segura e eficiente.

Em resumo, o Back-end é responsável por:

- receber dados enviados pelo usuário;
- validar esses dados;
- aplicar regras de negócio;
- acessar bancos de dados;
- comunicar-se com outros serviços;
- retornar respostas ao Front-end.

---

## O que é Front-end?

O **Front-end** é a parte da aplicação com a qual o usuário interage diretamente.

Seu principal objetivo é proporcionar uma boa experiência ao usuário (**UX - User Experience**), garantindo que a interface seja agradável, intuitiva, acessível e responsiva.

O Front-end é responsável por transformar as informações fornecidas pelo Back-end em uma interface visual.

Seu foco está em:

- interface gráfica;
- experiência do usuário;
- responsividade;
- acessibilidade;
- desempenho da aplicação.

---

## Responsabilidades do Back-end

### Gerenciamento de dados

Responsável por:

- armazenar dados;
- recuperar informações;
- manipular registros;
- garantir integridade e segurança dos dados.

---

### Lógica de negócio

Implementa todas as regras que definem o funcionamento da aplicação.

Exemplos:

- validar CPF;
- verificar permissões de acesso;
- calcular descontos;
- impedir operações inválidas;
- processar solicitações dos usuários.

---

### Desenvolvimento de APIs

O Back-end cria e mantém **APIs**, que permitem a comunicação entre diferentes sistemas ou entre o Front-end e o servidor.

Por meio das APIs, é possível:

- consultar informações;
- salvar dados;
- enviar e-mails;
- gerar documentos;
- enviar notificações;
- integrar serviços de terceiros.

---

### Administração do banco de dados

Também é responsabilidade do Back-end:

- gerenciar bancos de dados;
- otimizar consultas;
- garantir disponibilidade;
- manter a integridade das informações.

---

### Segurança

O Back-end controla o acesso aos recursos da aplicação.

Antes de fornecer qualquer informação, verifica se o usuário possui autorização para acessar aquele recurso.

Também é responsável por:

- autenticação;
- autorização;
- proteção de dados;
- tratamento de exceções.

---

## Responsabilidades do Front-end

### Interface do usuário (UI)

Desenvolver interfaces visualmente agradáveis e intuitivas para facilitar a interação do usuário.

---

### Desenvolvimento da interface

Escrever o código responsável por dar vida ao layout da aplicação.

Seu objetivo é garantir compatibilidade entre:

- navegadores;
- dispositivos;
- plataformas.

---

### Acessibilidade e usabilidade

Garantir que a aplicação seja fácil de utilizar por qualquer pessoa, inclusive usuários com necessidades especiais.

---

### Responsividade

Adaptar a interface para diferentes tamanhos de tela, como:

- smartphones;
- tablets;
- notebooks;
- monitores.

---

### Otimização de desempenho

Garantir que a interface carregue rapidamente e ofereça uma navegação fluida ao usuário.

---

## Comparação entre Back-end e Front-end

| Back-end | Front-end |
|---|---|
| Executa no servidor | Executa no navegador ou aplicativo |
| Trabalha nos bastidores | Trabalha na interface com o usuário |
| Processa dados | Exibe informações |
| Implementa regras de negócio | Implementa a interface gráfica |
| Desenvolve APIs | Consome APIs |
| Gerencia banco de dados | Apresenta os dados ao usuário |
| Foco nos dados | Foco na experiência do usuário |

---

## Resumo

| Área | Principal responsabilidade |
|---|---|
| **Back-end** | Processar dados, aplicar regras de negócio, acessar banco de dados, desenvolver APIs e garantir segurança |
| **Front-end** | Criar interfaces, proporcionar boa experiência ao usuário, garantir responsividade, acessibilidade e desempenho |
| **Mobile** | Desenvolver aplicações voltadas para dispositivos móveis (Android e iOS), aplicando conceitos de Front-end adaptados ao ambiente mobile |
