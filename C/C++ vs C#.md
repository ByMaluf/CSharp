# CSharp

| Tipo | C/C++ | C# |
|---|---|---|
| Tipo | C é uma linguagem de baixo e C++ é intermediária | Linguagem de alto nível |
| Compilação | Compila o programa para linguagem de máquina | Compila o programa para Common Language Runtime (CLR) |
| Plataforma | Linux, Windows, macOS, etc | Linux, Windows, macOS, etc |
| Orientação a objetos | (C++ apenas) Suporta orientação a objetos mas não é completamente orientada | Puramente orientada a objetos |
| Tamanho dos binários | O tamanho dos binários é menor | O tamanho dos binários é maior |
| Switch | Não aceita tipo string no controle de fluxo | Pode ser usado strings para controlar o fluxo |
| Velocidade | Uma das linguagens mais rápidas | Rápido, mas perde com bastante diferença em relação à velocidade e desempenho |
| Erros | Não avisa nos devs se houver algum erro de sintaxe antes da compilação | Avisa sobre os erros do compilador |
| Garbage collector | Não oferece suporte à limpeza de partes não referenciadas de um programa | Oferece suporte à limpeza de partes não referenciadas de um programa |
| Gerenciamento de memória | Feito manualmente | Feito automaticamente |
